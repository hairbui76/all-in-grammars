# Adjective Preposition Combinations

> [!abstract] In one line
> Many adjectives take one fixed preposition before their complement, and the choice is lexical — it must be memorised.

## Form

`be + adjective + preposition + noun / pronoun / V-ing`

## Feelings and attitude

| Combination | Meaning |
|---|---|
| be kind / nice / good **to** sb | behave well towards someone |
| be good **for** sb | beneficial |
| be good **at** smth | skilled in |
| be good **with** (one's hands) | dexterous |
| be quick **at** smth | fast at |
| be skilful **at** smth | skilled at |
| be serious **about** smth | not joking about |
| be angry **with** sb **about** smth | annoyed |
| be sad / happy **about** smth | feel sad / glad |
| be upset **about** smth | distressed |
| be sorry **for / about** smth | regret |
| be pleased **with** smth | satisfied |
| be interested **in** smth | curious about |
| be keen **on** doing smth | enthusiastic about |
| be fond **of** smth | like |
| be tired **of** doing smth | bored with |
| be tired **from** doing smth | physically exhausted by |
| be surprised **at** smth | astonished |
| be confused **about** smth | muddled about |
| be indifferent **to** smth | not caring about |
| be suspicious **of** smth | distrustful |
| be confident **of** smth | sure about |
| be ashamed **of** doing smth | feel shame for having done |
| be ashamed **to do** smth | feel shame at having to do |

## Fear

- be afraid **of** smth
- be frightened **of** smth
- be scared **of** smth
- be terrified **of** smth

## Relations and comparison

| Combination | Meaning |
|---|---|
| be different **from** | unlike |
| be similar **to** smth | like |
| be popular **with** sb | liked by |
| be friendly **with** sb | on close terms with |
| be / get acquainted **with** sb | come to know |
| be / get married **to** sb | marry |
| be engaged **to** sb | betrothed to |
| be dependent **on** sb **for** smth | rely on |
| be independent **of** sb | not rely on |
| be far **from** | a long way from |
| contrary **to** + N | opposed to |

## States and circumstances

| Combination | Meaning |
|---|---|
| be late **for** work / school | arrive after time |
| be present **at** | attend |
| be absent **from** | not attend |
| be crowded **with** / packed **with** | full of people |
| be full **of** | containing a lot of |
| be rich **in** | having a lot of |
| be short **of** money | not having enough |
| be successful **in** smth | do well in |
| be famous **for** smth | well known because of |
| be responsible **to** sb **for** smth | answerable |
| be capable **of** doing smth | able to |
| be available **for** sb | at someone's disposal |
| be aware / unaware **of** smth | know / not know |
| be important **to** sb | matter to |
| be harmful **to** | damaging for |
| be perfect **for** smth | ideally suited |
| be favourable **for** smth | advantageous |
| be open **to** sb | accessible to |
| be grateful / obliged / indebted **to** sb **for** smth | thankful |
| be / get used **to** smth / doing smth | be familiar with by habit |
| be accustomed **to** smth / doing smth | be in the habit of |
| be in the habit **of** doing smth | habitually do |

## Notes & exceptions

- `be used to + V-ing` (be familiar with) is not the same as `used to + V` (a past habit) → see [[Used To And Would For Past Habits]].
- `be tired of` = bored, but `be tired from` = physically worn out.
- After a preposition, a verb always takes the `-ing` form → see [[Gerund After Prepositions]].
