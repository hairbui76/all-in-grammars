# Adjectives Ending in -ed and -ing

> [!abstract] In one line
> `-ed` adjectives say how a person **feels**; `-ing` adjectives say what **causes** that feeling.

## Form

```
Person + be/feel/look + Adjective-ed        -> the feeling experienced
Thing/Person + be + Adjective-ing           -> the source of the feeling
```

## The pairs

| `-ed` (feeling) | `-ing` (cause) |
| --- | --- |
| interested | interesting |
| bored | boring |
| excited | exciting |
| annoyed | annoying |
| surprised | surprising |
| frightened | frightening |
| embarrassed | embarrassing |
| amused | amusing |
| confused | confusing |
| thrilled | thrilling |
| worried | worrying |
| tired | tiring |
| horrified | horrifying |
| shocked | shocking |

## Examples

`-ed` — the emotion someone feels:

- He feels **frightened**.
- I'm **interested** in everyone I meet.
- I'm sure you must be very **tired** after working so hard.
- The students felt **bored**.

`-ing` — the thing that produces the emotion:

- The ghost story is **frightening**.
- The teacher was **boring**.
- Reading novels of famous authors is quite **interesting**.
- Arguing with that talkative woman is **boring**.

## Notes & exceptions

- Both forms are true participles, so they can also be used attributively: *a frightened child*, *a frightening film*.
- Saying *I am boring* means "I make other people bored" — a very common and unintentionally rude mistake.

## Common mistakes

- ❌ I was very boring during the lecture. → ✅ I was very **bored** during the lecture.
- ❌ The film was very interested. → ✅ The film was very **interesting**.
