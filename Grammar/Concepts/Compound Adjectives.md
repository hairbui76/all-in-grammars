# Compound Adjectives

> [!abstract] In one line
> Two (or more) words are joined, usually with a hyphen, to form a single new word that works as one adjective.

## Patterns

| Pattern | Examples |
| --- | --- |
| Noun + Adjective | sea-sick, ankle-deep |
| Noun + Present participle | machine-repairing, hydrogen-containing |
| Noun + Past participle | hand-made, city-run |
| Adjective + Adjective | red-hot, dark-blue |
| Adjective + Noun + `-ed` | blue-eyed, good-tempered |
| Adjective + Noun | long-distance, high-quality |
| Adjective + Present participle | fine-looking, easy-going |
| Adjective + Past participle | ready-made, clear-cut |
| Adverb + Present participle | far-reaching, hard-working |
| Adverb + Past participle | newly-invented, well-known |
| Noun + `tight` | air-tight, water-tight |
| Noun + `proof` | bullet-proof, shock-proof |
| Noun + `free` | duty-free, pollution-free |
| Cardinal number + singular noun | a **two-year-old** child, an **eight-hour** day |

## Examples

- She bought a **hand-made** silk scarf.
- He is a **hard-working** and **good-tempered** colleague.
- They live in a **long-distance** relationship.
- We stayed in a **newly-invented** capsule hotel.
- I bought it in the **duty-free** shop.
- It was an **eight-hour** day.

## Notes & exceptions

- In the number pattern the noun stays **singular**: `a two-year-old child`, not ~~a two-years-old child~~; `an eight-hour day`, not ~~an eight-hours day~~.
- A compound adjective normally keeps its hyphen only in attributive position: *a well-known writer* but *the writer is well known*.

## Common mistakes

- ❌ a six-years-old boy → ✅ a **six-year-old** boy
- ❌ a ten-kilometres walk → ✅ a **ten-kilometre** walk
