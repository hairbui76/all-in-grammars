# Conditional Conjunctions

> [!abstract] In one line
> A set of connectors that can replace `if` and add a shade of meaning: supposition, restriction, precaution or concession.

## Form

| Connector | Meaning | Followed by |
|---|---|---|
| `suppose / supposing (that)` | suppose, let's imagine | clause |
| `in case` | in case (as a precaution, before it happens) | clause |
| `in case of` | in the event of (after it happens) | noun |
| `even if` | even if, although | clause |
| `as long as / so long as` | on the sole condition that | clause |
| `provided (that) / providing (that)` | provided that | clause |
| `on condition (that)` | on condition that | clause |

## When to use

- `provided that / as long as / on condition that` set a strict requirement — stronger and more restrictive than plain `if`.
- `in case` states a precaution taken **before** the event, whether or not it happens; `in case of + noun` refers to what to do **when** it does happen.
- `even if` concedes that the result holds regardless of the condition.
- `suppose / supposing` opens a hypothesis, often in questions.

## Examples

- **Suppose** the news is true, what will you do?
- I'll change my decision **provided that** you accept my offer.
- **In case** I forget, please remind me of my promise.
- I will lend you my car **so long as** you fill it up with petrol.
- **As long as / Provided that / Providing that** you fill it up with petrol, I will lend you my car.

## Notes & exceptions

- These connectors normally keep the tense pattern of the conditional type they replace.
- `in case` is not the same as `if`: *Take an umbrella in case it rains* (precaution) vs *Take an umbrella if it rains* (condition).
