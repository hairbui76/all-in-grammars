# Expressions Followed By Gerund

> [!abstract] In one line
> A set of fixed expressions about ability, usefulness and value are always completed by an `-ing` form.

## Form

| Expression | Meaning |
|---|---|
| `can't help / can't resist + V-ing` | cannot avoid doing |
| `can't bear / can't stand + V-ing` | cannot endure doing |
| `It's no use / no good + V-ing` | it is useless doing |
| `There's no point in + V-ing` | there is no purpose in doing |
| `There's no harm in + V-ing` | it does no harm to do |
| `It's a waste of time + V-ing` | it is a waste of time doing |
| `It's (not) worth + V-ing` | it is (not) worth doing |

## Examples

- My mother can't stand **seeing** me at home all day.
- He told me a funny story. I couldn't help **laughing**.
- It's no good/use **arguing**.
- There's nothing you can do about the situation, so it's no use **worrying** about it.
- There was no point in **waiting** any longer, so we went.
- It's a waste of time **buying** things you don't need.
- In my opinion, there's no harm in **smoking** one or two cigarettes a day.
- Is there anything here worth **buying**?
- I live only a short walk from here, so it's not worth **taking** a taxi.

## Notes & exceptions

- With `worth`, the thing evaluated becomes the subject: *A film is worth **seeing**.* / *A book is worth **reading**.*
  - What was the film like? Was it worth **seeing**?
  - I don't think these books are worth **reading**.
- `It's no use`, `there's no point in`, `it's no good` also allow a possessive/object before the gerund → see [[Possessive With Gerund]].

## Common mistakes

- ❌ It's no use to argue. → ✅ It's no use **arguing**.
- ❌ This book is worth to read. → ✅ This book is worth **reading**.
