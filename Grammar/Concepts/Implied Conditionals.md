# Implied Conditionals

> [!abstract] In one line
> A conditional meaning can be carried without any if-clause, by `otherwise`, by an imperative + `or`, or by `What a pity ...`.

## Form

```
Imperative + or + clause          =  If + S + don't/aren't + ..., clause
Statement. Otherwise + clause     =  If it were / had been otherwise, clause
```

## When to use

- Spoken warnings and threats, where the imperative is shorter than an if-clause
- Follow-up sentences where the condition has already been stated, so `otherwise` refers back to it

## Examples

Imperative + `or`:

- **Go away or** I will call the police. → If you **don't go** away, I will call the police.
- **Be careful or** you will cut yourself. → If you **aren't careful**, you will cut yourself.

`Otherwise`:

- I am not rich. **Otherwise** I would help the poor. (= If I were rich, I would help the poor.)
- He arrived at the station too late. **Otherwise** he would have caught the train.

Regret used as an implied conditional:

- **What a pity** you didn't watch the game. You **would have liked** it.

## Notes & exceptions

- `Otherwise` takes the modal form of the conditional type implied: `would + V` for present unreal, `would have + V3` for past unreal.
- The imperative + `or` pattern always converts into a **negative** if-clause.
