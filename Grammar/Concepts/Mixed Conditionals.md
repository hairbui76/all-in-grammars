# Mixed Conditionals

> [!abstract] In one line
> The condition and the result belong to different times, so the two clauses come from different conditional types.

## Form

Two combinations are used:

```
(1) If + S + V(past simple),        S + would have + V3      -> unreal present condition, unreal past result
(2) If + S + had + V3,              S + would + V(bare)      -> unreal past condition, unreal present result
```

In other words, the if-clause of one type is joined to the main clause of the other.

## When to use

- Use pattern (1) when a permanent present fact explains something that did not happen in the past.
- Use pattern (2) when something that did not happen in the past explains a present state.

## Examples

Type 2 if-clause + type 3 main clause:

- If I **were** you, I **wouldn't have been** so rude to him.
- If he **didn't love** his wife, he **would not have married** her.

Type 3 if-clause + type 2 main clause:

- If I **hadn't stayed** up late last night, I **wouldn't feel** sleepy now.
- If you **had taken** my advice, things **would be** different now.
- If I **had studied** hard at school, I **would** not **have to work** as a cleaner now.

## Notes & exceptions

- Time words (`last night`, `now`, `today`) are the clearest signal that a mixed pattern is needed.
- The main clause of pattern (2) may use `would`, `could` or `might` depending on the meaning.
