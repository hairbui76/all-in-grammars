# Modal Perfect Infinitive

> [!abstract] In one line
> A modal verb followed by `have + past participle` talks about the past: deduction, unrealised possibility, criticism or regret.

## Form

`S + modal + have + PII`

## Overview table

| Structure | Meaning | Equivalent |
|---|---|---|
| `must have + PII` | I'm certain it happened | `I'm sure + past simple clause` |
| `may / might / could have + PII` | perhaps it happened | `Perhaps + past simple clause` |
| `can't / couldn't have + PII` | I'm certain it did not happen | `I'm sure + negative past clause` |
| `should / ought to have + PII` | it was advisable but was not done | criticism, regret |
| `shouldn't have + PII` | it was done but was wrong | criticism |
| `needn't have + PII` | it was done but was unnecessary | |
| `could have + PII` | it was possible but was not done | missed opportunity |
| `would like / would rather have + PII` | an unreal wish about the past | `wish + had + PII` |

## Examples

- I've lost my key. I **must have dropped** it somewhere in this room.
- A sea monster **might have attacked** the ship.
- The ground is dry. It **can't have rained** last night.
- You **should have told** her the truth.
- You **needn't have hurried**. We are too early now.
- I had free time but I went to bed early. I **could have done** all my homework.
- I'd **rather have been born** rich.
- I **might have got** a better job if I had studied hard enough.

## Notes & exceptions

- The continuous version is `modal + have been + V-ing` → see [[Perfect Continuous Infinitive]].
- `would / could / might have + PII` is also the main clause of a [[Third Conditional]].
