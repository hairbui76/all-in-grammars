# Need Doing and Need To Be Done

> [!abstract] In one line
> `need to do` has an active meaning, while `need doing` and `need to be done` both have a passive meaning — but only `need to be done` can be used with people.

## Form

- `S + need + to + V` — active: the subject must perform the action.
- `S + need + V-ing` = `S + need + to be + P2` — passive: the subject must receive the action.

## When to use

- Use `need doing` freely with **things**; it is interchangeable with `need to be done`.
- With **people**, use only `need to be done`. `Need + V-ing` is not used for persons.

## Examples

- You **need to work** harder. (active — you do the working)
- This car **needs to be serviced**. / This car **needs servicing**.
- I need to clean my shirt because it **needs cleaning** / **to be cleaned**.
- The old **need to be looked after** by the young.

## Common mistakes

- ❌ The old need looking after by the young. → ✅ The old **need to be looked after** by the young.

## Contrast with

- [[Passive Gerund]] — `being + P2`, the ordinary passive `-ing` form
- [[Passive Infinitive]] — `to be + P2`
