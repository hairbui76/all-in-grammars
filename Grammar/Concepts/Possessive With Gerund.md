# Possessive With Gerund

> [!abstract] In one line
> Putting a possessive adjective or an object pronoun in front of a gerund shows that somebody other than the subject performs the action.

## Form

```
S + V (+ preposition) + V-ing            → the gerund refers to the subject
S + V (+ preposition) + my/his/me/him + V-ing → the gerund refers to that person
```

## When to use

- Use the plain gerund when subject and gerund action belong to the same person.
- Insert a possessive adjective (`my, his, her, their`) or an object pronoun (`me, him, her, them`) when the action belongs to somebody else.

## Examples

- I don't mind **getting** up early. (I get up early.)
- Tom insisted on **reading** the letter. (Tom read it.)
- He insisted on **my/me reading** it. (I had to read it.)
- He disliked **working** late. / He disliked **me/my working** late.
- I object to **paying** twice for the same thing. / I object to **his/him making** private calls on this phone.
- He resented **being** passed over for promotion. / He resented **my/me being** promoted before him.

## Notes & exceptions

- Verbs and expressions that allow both patterns include: `dislike, propose, understand, dread, recollect, approve/disapprove of, fancy, remember, insist on, involve, resent, like (negative), save, object to, mean, stop, mind, suggest`, plus `it's no good/use`, `there's no point in`, `what's the point of`.
- The possessive form (`my`) is more formal; the object pronoun (`me`) is more common in speech.

## Common mistakes

- ❌ He insisted on I read it. → ✅ He insisted on **my/me reading** it.
