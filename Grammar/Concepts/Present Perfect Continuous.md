# Present Perfect Continuous

> [!abstract] In one line
> Stresses how long an action has been going on from the past up to now.

## Form

```
(+) S + have/has + been + V-ing
(-) S + have/has + not + been + V-ing
(?) Have/Has + S + been + V-ing?
```

## When to use

- An action that started in the past, has continued up to now, and will probably go on
- An action that has only just stopped, where the speaker can point to visible evidence
- A habit or repeated action stretching from the past to the present

## Examples

- It is raining. It **has been raining** since I got up.
- Her eyes are red. She **has been crying**.
- He **has been playing** the piano since she was five.

## Notes & exceptions

- Questions about duration begin with `How long ...?`: *How long **have** you **been teaching**?*
- Stative verbs (`be, know, like, belong, have (= possess), need, remember`) are not used in this tense; use [[Present Perfect]] instead.
- `always` is not used with this tense: *I **have always loved** you*, not *have always been loving*.

## Contrast with

- [[Present Perfect vs Present Perfect Continuous]]
- [[Present Continuous]] — no link to a starting point in the past
- [[Past Perfect Continuous]] — the same aspect measured up to a past point
