# Present Perfect vs Present Perfect Continuous

> [!abstract] In one line
> The perfect points at the RESULT reached by now; the perfect continuous points at the ACTIVITY that produced it.

## Contrast

| | Present perfect | Present perfect continuous |
|---|---|---|
| Focus | the result up to now; the action itself is not the point | the continuity of the action; the result is not the point |
| Form | `S + have/has + past participle` | `S + have/has + been + V-ing` |
| Example | I **have done** my homework. | I **have been doing** my homework. |
| Example | He **has saved** 500 million pounds. | He **has been saving** money since he started work. |
| Example | They **have decorated** the living room. | They **have been decorating** the living room. |
| Typical question | `How much ...?` / `How many ...?` — asking about the result | `How long ...?` — asking about the duration |
| Question example | How many lessons of this book **have** you **learnt**? | How long **have** you **been teaching**? |
| Question example | How many times **has** he **been** to Paris? | How long **has** she **been writing** this novel? |

## Notes & exceptions

- With stative verbs only the present perfect is possible, even when the meaning is durational: *How long **have** they **known** each other?* · *They **have loved** each other since their schooldays.*
- `always` goes with the present perfect only: *My parents **have always lived** in London.*
