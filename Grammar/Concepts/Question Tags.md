# Question Tags

> [!abstract] In one line
> A short question added to a statement to ask for confirmation: positive statement → negative tag, and vice versa.

## Form

`Positive statement + negative tag?` — *You are ready, **aren't you**?*
`Negative statement + positive tag?` — *You aren't ready, **are you**?`

The tag repeats the **auxiliary** (or `be`) plus a **subject pronoun**. If there is no auxiliary, use `do / does / did`.

- *She works here, **doesn't she**?*
- *They went home, **didn't they**?*
- *He can swim, **can't he**?*
- *You have finished, **haven't you**?*

## When to use

- To invite agreement (falling intonation) or to ask a real question (rising intonation).
- Common in speaking tests and in "choose the correct tag" exam items.

### Special tags to memorise

| Statement | Tag |
|---|---|
| I **am** late, | **aren't I**? |
| **Let's** go, | **shall we**? |
| Open the door, | **will/won't you**? |
| Don't be late, | **will you**? |
| There **is** a problem, | **isn't there**? |
| **Everyone / Somebody** knows, | **don't they**? |
| **Nothing / Everything** is ready, | **is it**? |
| **I think** he is right, | **isn't he**? (tag follows the *that*-clause) |
| **I used to** live here, | **didn't I**? |
| **I'd better** go, | **hadn't I**? |
| **You'd rather** stay, | **wouldn't you**? |
| **This / That** is yours, | **isn't it**? |
| **These / Those** are new, | **aren't they**? |
| **One** should try, | **shouldn't one/they**? |

## Examples

- You **haven't** seen my keys, **have you**?
- Let's take a break, **shall we**?
- Nobody phoned, **did they**?
- I'm the next speaker, **aren't I**?
- I don't think she agrees, **does she**?

## Notes & exceptions

- With `I think / I suppose / I believe + clause`, the tag agrees with the **subordinate** clause; if the main verb is negative (`I don't think he is right`), the tag stays positive (`**is he**?`).
- `nobody, no one, everyone, someone` are referred to as `they` in the tag.
- `nothing, everything, something` are referred to as `it`.
- A statement containing a negative word is treated as negative → see [[Question Tags With Negative Adverbs]].

## Common mistakes

- ❌ You are a student, isn't it? → ✅ You are a student, **aren't you**? (the tag must copy the auxiliary and subject)
- ❌ Let's go, will we? → ✅ Let's go, **shall we**?
- ❌ I am right, amn't I? → ✅ I am right, **aren't I**?
