# Spelling Rules for -ED Forms

> [!abstract] In one line
> How `-ed` is attached to a regular verb to make its past simple and past participle.

## Rules

| Rule | Condition | Examples |
|---|---|---|
| 1 | Default → add `-ed` | visit → visit**ed**, play → play**ed** |
| 2 | Verb ends in `-e` → add `-d` only | live → live**d** |
| 3 | Consonant + `y` → change `y` to `i`, add `-ed` | study → stud**ied** |
| 4 | Vowel + `y` → keep the `y`, add `-ed` | play → play**ed** |
| 5 | One-syllable verb ending in one vowel + one consonant → double the consonant | stop → sto**pped**, step → ste**pped**, plan → pla**nned** |
| 6 | Two-syllable verb ending in one vowel + one consonant, stressed on the second syllable → double the consonant | permit → permi**tted**, admit → admi**tted** |

## Notes & exceptions

- Rule 6 depends on stress: *per**MIT*** doubles, but *`VIS`it* does not.
- These rules produce the spelling only; how the ending is READ is a separate rule — see [[Pronunciation of -ED Endings]].
- Irregular verbs ignore all of this and must be memorised.
