# Spelling Rules for -ing Forms

> [!abstract] In one line
> Six spelling rules govern how `-ing` is attached to a verb.

## Rules

| Rule | Condition | Examples |
|---|---|---|
| 1 | Two vowels + one consonant; two consonants; pronounced `e`; final `y` → just add `-ing` | read → read**ing**, work → work**ing**, see → see**ing**, fly → fly**ing** |
| 2 | Silent `e` after a consonant → drop the `e`, add `-ing` | write → writ**ing**, live → liv**ing**, type → typ**ing**, smoke → smok**ing** |
| 3 | Verb ends in `-ie` → change `ie` to `y`, add `-ing` | lie → l**ying**, die → d**ying**, tie → t**ying** |
| 4 | One-syllable verb, one vowel + one consonant → double the final consonant | get → ge**tting**, run → ru**nning**, sit → si**tting**, fit → fi**tting**, swim → swi**mming**, plan → pla**nning** |
| 5 | Two-syllable verb, one vowel + one consonant → double the final consonant | begin → begi**nning**, forget → forge**tting**, permit → permi**tting** |
| 6 | Verb ends in `-c` → add `k`, then `-ing` | picnic → picnic**king**, mimic → mimic**king**, traffic → traffic**king** |

## Notes & exceptions

- Rule 3 exists so that the spelling `*lieing` is avoided; the result is `lying`, `dying`, `tying`.
- Rules 4 and 5 apply only when the verb ends in exactly one vowel + one consonant; `read` (two vowels) and `work` (two consonants) take no doubling.
