# Suffixes That Shift Stress to the Previous Syllable

> [!abstract] In one line
> These endings are not stressed themselves, but they force the primary stress onto the syllable immediately in front of them.

## Rule

`... + STRESSED syllable + suffix` → stress on the syllable directly before the suffix

## The list

| Suffix | Examples with transcription |
|---|---|
| **-ion** | population /ˌpɒpjʊˈleɪʃn/ |
| **-ic** | economic /ˌiːkəˈnɒmɪk/ |
| **-ial** | industrial /ɪnˈdʌstriəl/ |
| **-ive** | expensive /ɪkˈspensɪv/ |
| **-ible** | responsible /rɪˈspɒnsɪbl/ |
| **-ity** | ability /əˈbɪləti/ |
| **-graphy** | photography /fəˈtɒɡrəfi/ |
| **-ious / -eous** | industrious /ɪnˈdʌstriəs/, advantageous /ˌædvənˈteɪdʒəs/ |
| **-ish** | selfish /ˈselfɪʃ/ |
| **-ian** | politician /ˌpɒlɪˈtɪʃn/ |

## Notes & exceptions

- The rule still applies when a neutral ending is added on top: `historical` /hɪˈstɒrɪkl/ — `-al` is neutral, so `-ic` decides the stress.
- `internationally` /ˌɪntəˈnæʃnəli/ — `-ly` and `-al` are neutral, so `-ion` decides the stress.
- Irregular members: politics /ˈpɒlətɪks/, lunatic /ˈluːnətɪk/, rhetoric /ˈretərɪk/, television /ˈtelɪvɪʒn/, primitive /ˈprɪmɪtɪv/ → see [[Word Stress Exceptions]].
