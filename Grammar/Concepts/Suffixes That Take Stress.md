# Suffixes That Take Stress

> [!abstract] In one line
> A small group of endings is itself stressed, so the primary stress lands on the suffix rather than on the root.

## Rule

`root + stressed suffix` → primary stress falls **on the suffix**

## The list

| Suffix | Examples with transcription |
|---|---|
| **-eer** | volunteer /ˌvɒlənˈtɪə/, career /kəˈrɪə/ |
| **-ee** | employee /emplɔɪˈiː/, interviewee /ˌɪntəvjuːˈiː/ |
| **-oo** | bamboo /ˌbamˈbuː/, taboo /təˈbuː/ |
| **-oon** | afternoon /ˌɑːftəˈnuːn/, cartoon /kɑːˈtuːn/ |
| **-ese** | Vietnamese /ˌvɪetnəˈmiːz/ |
| **-ette** | cigarette /ˌsɪɡəˈret/ |
| **-esque** | picturesque /ˌpɪktʃəˈresk/ |
| **-ade** | lemonade /ˌleməˈneɪd/ |
| **-mental** | environmental /ɪnˌvaɪərənˈmentl/ |
| **-nental** | continental /ˌkɒntɪˈnentl/ |
| **-ain** | entertain /ˌentəˈteɪn/ |

## Notes & exceptions

- `-ee` / `-eer` have well-known exceptions: coffee /ˈkɒfi/, reindeer /ˈreɪndɪə/, committee /kəˈmɪti/, employee /ɪmˈplɔɪiː/ (also /ˌemplɔɪˈiː/) → see [[Word Stress Exceptions]].
- Because `-ain` is stressed, a word like `entertainment` (where `-ment` is neutral) still stresses the third syllable: /ˌentəˈteɪnmənt/.
