# Verb Preposition Combinations

> [!abstract] In one line
> Many verbs are followed by a fixed preposition before their object, and changing the preposition changes or destroys the meaning.

## Form

`V + preposition + noun / pronoun / V-ing`
`V + object + preposition + noun / pronoun / V-ing`

## Verb + preposition

| Combination | Meaning |
|---|---|
| succeed **in** doing smth | manage to do |
| believe **in** | trust in the value of |
| belong **to** | be the property of |
| care **for** | like, look after |
| depend / rely **on** sb **for** smth | count on |
| suffer **from** = put up **with** | endure |
| crash **into** | collide with |
| laugh **at** sb | make fun of |
| shout **at** sb | shout in anger |
| shout **to** sb | call out to |
| wait **for** sb | await |
| wait up **for** sb | stay up until sb arrives |
| pay **for** smth | give money for |
| think **of** smth | come up with |
| think **about** smth | consider |
| dream **of** smth | long for |
| dream **about** sb | see in a dream |
| hear **from** sb | receive news from |
| hear **of** sb | know that sb exists |
| hear **about** smth | be told about |
| happen **to** sb | occur to |
| die **of** smth | die because of |
| die **out** | become extinct |
| die **down** | fade away |
| write **to** sb | send a letter to |
| look **at** smth | direct one's eyes at |
| look **after** sb | take care of |
| look **for** = search **for** = seek | try to find |
| look **into** | investigate |
| complain **to** sb **about** smth | make a complaint |
| apologise **to** sb **for** smth | say sorry |
| go **off** | ring; explode |

## Verb + object + preposition

| Combination | Meaning |
|---|---|
| accuse sb **of** smth | say sb did wrong |
| blame sb **for** smth | hold responsible |
| ask sb **for** smth | request |
| ask **after** sb | enquire about sb's health |
| congratulate sb **on** smth | offer congratulations |
| explain smth **to** sb | make clear to |
| divide smth **into** | split into parts |
| invite sb **to** somewhere | ask sb to come |
| impress sb / make an impression **on** sb | leave a strong effect |
| leave sb **behind** | not take sb along |
| leave **out** = omit | not include |
| leave **off** | stop |
| leave home **for** work | set off to |

## Fixed verb + noun + preposition phrases

| Phrase | Meaning |
|---|---|
| take care **of** | look after |
| take notice **of** | pay attention to |
| take advantage **of** smth | exploit |
| take account **of** smth = take smth **into** account | consider |
| make use **of** = use | put to use |
| make fun **of** sb | mock |
| make room **for** | create space for |
| make way **for** | let pass |
| make a fuss **over** smth | fret about |
| keep pace **with** | move as fast as |
| keep in touch **with** sb | stay in contact |
| lose touch **with** sb | stop being in contact |
| lose control **of** | no longer control |
| give way **to** | yield to |
| have a look **at** smth | look at |

## Notes & exceptions

- Some pairs differ only in the preposition but not in the object: `shout at` (angry) vs `shout to` (calling); `think of` (invent) vs `think about` (consider).
- A verb + preposition combination that keeps its literal meaning is not the same as a phrasal verb with an idiomatic meaning → see [[Phrasal Verbs]].
- Any verb after these prepositions takes `-ing` → see [[Gerund After Prepositions]].
